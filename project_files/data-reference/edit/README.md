Пример: передача А создана в 1С раньше Б, но её финальное сообщение пришло после финала Б — применится А и заменит прайс Б. Если же финал А пришёл раньше финала Б, а позже — только обычные пакеты А, то собравшаяся А уже старше применённой Б и прайс не заменит. Формулировка: «применяется передача, финальное сообщение которой принято сервисом последним; при равенстве — собравшаяся позже». |
| 2 | `dataVersion отсутствует — применяется последняя финализированная передача.` | **«Последняя» — по моменту приёма финала.** Уточнить так же, как пункт выше: «dataVersion отсутствует — применяется передача, финальное сообщение которой принято последним». |

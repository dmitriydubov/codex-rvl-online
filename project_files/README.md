# Документы контура РВЛ ОНЛАЙН

Источники предметной области: ТЗ, схемы, структуры данных. Разложены по сервисам.

| Каталог | Что внутри |
|---|---|
| `common/` | документы контура целиком и соседей: схемы процесса и флоу, ФТ к модулю РВЛ, вопросы и ответы, точки интеграции с 1С:УСК, структура данных сервиса Заявок |
| `data-reference/` | сервис справочных данных: ТЗ API и журнал решений REST (при расхождении прав журнал), структура БД, потоки 1С:УСК ТЗ-01…ТЗ-10 (`1C_data/`), копии ТЗ с предлагаемыми правками (`edit/`) |
| `contract-service/` | сервис Договоров — появится, когда его документы перенесут сюда из `contract-service/project_files/` и корня этого каталога |

В рабочий контур каталог не переносится: в документах есть персональные данные и внутренние адреса.

# test ran, so nothing proved the mutant dead. A line here says a human read the tests and named the
# assertion that fails for the mutant. The key is the method and the mutator, not the line number: RUN_ERROR
# is not deterministic (another run crashes on another mutant, or on none), and line numbers go stale.

# tests when the method grows a new conditional, return or lambda. Agents cannot edit this file.
#
# Before adding a line: run the tests, read the mutated line, find the assertion that fails for exactly
# this mutation. A mutant with no such assertion is a weak test, not an allowlist entry.
